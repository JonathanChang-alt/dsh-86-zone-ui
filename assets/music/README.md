# 音频目录

把三首曲子放进来，文件名**必须**是下面这些（扩展名 `mp3 / m4a / ogg / flac / wav` 都可以，
插件按这个顺序查找）：

| 文件名 | 曲目 | 面板显示 |
|---|---|---|
| `avid.mp3` | AVID | 01 |
| `voice-of-the-chord.mp3` | Voice of the Chord | 02 |
| `hands-up-to-the-sky.mp3` | Hands Up to the Sky | 03 |

放好之后**不需要重启**，在状态台的 COMMS 面板里点曲目就会开始播。
如果显示 `音源未接入 → assets/music/avid.mp3`，说明文件名对不上或目录不对。
